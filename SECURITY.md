# Security Policy

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/NeatMacApps/NeatWebApp/security/advisories/new).

Include the affected version, macOS version, reproduction steps, and impact. Do not include real passwords, cookies, session tokens, or other private account data in a report. Use a disposable test account and redact diagnostic output before sharing it.

Please do not open a public issue for an undisclosed vulnerability.
