# 2026-09-05：菜单栏宿主进程突然消失（内存压力回调闪退）

## 症状

- 菜单栏里的 NeatWebApp 图标突然没了，主进程不在活动监视器里。
- 已打开的网页应用窗口/侧边栏图标可能还在（内嵌运行时进程还活着），但宿主已退出。
- 系统诊断里可见 `NeatWebApp-*.ips`，不是用户点退出。

## 根因

宿主订阅系统内存压力时，事件回调跑在后台队列，却继承了「必须在主线程」的隔离约束。Swift 6 运行时在回调入口做断言失败 → `EXC_BREAKPOINT` / `SIGTRAP`（栈顶常见 `_dispatch_assert_queue_fail` → `_swift_task_checkIsolatedSwift`）。

本机两份报告时间：2026-09-05 19:31、20:01；符号化落在 `HostMemoryPressureMonitor` 初始化里的事件闭包。系统一报 warning/critical 压力就会杀宿主——本意是收缩图标缓存，结果整进程闪退。

## 修复

事件闭包标成可跨线程传递，且不在后台队列碰主线程对象；真正清缓存时再回到主线程。见 `HostMemoryPressureMonitor.swift`。

## 禁止的误修

- 不要为消闪退拆掉内存压力订阅或改成「压力下来杀运行时 / 卸网页」。
- 不要把 `@MainActor` 加回整类后再用 `assumeIsolated` 糊弄后台回调。

## 验收

覆盖安装后宿主能常驻；人为制造内存压力（或等系统自然压力）后进程仍在，图标缓存可被清掉，已收起的网页应用仍秒开。
