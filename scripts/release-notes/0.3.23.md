# NeatWebApp 0.3.23

- Added a persistent two-column dotted grip to the floating activity Dock so its drag target is clear. The compact grip stays visible when app icons scroll and uses solid dots without hollow rings or blurred halos.
- Kept native free dragging and remembered placement; no collapse or expand controls.
- Shortened browser menu labels for faster scanning.

## 简体中文

- 悬浮活动 Dock 增加常驻双列点阵手柄，让拖动入口清晰可见；手柄区域保持紧凑，图标滚动时仍可见，使用实心圆点，去掉空心圈和模糊光晕。
- 保留原生自由拖动和位置记忆，不增加展开或收缩控件。
- 缩短浏览器菜单名称，便于快速查找。
