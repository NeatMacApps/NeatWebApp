# NeatWebApp 0.3.23

- Added a persistent two-column dotted grip to the floating activity Dock so its drag target is clear. The compact grip stays visible when app icons scroll and uses a contrasting foreground over light and dark desktop content.
- Kept native free dragging and remembered placement; no collapse or expand controls.
- Shortened browser menu labels for faster scanning.

## 简体中文

- 悬浮活动 Dock 增加常驻双列点阵手柄，让拖动入口清晰可见；手柄区域保持紧凑，图标滚动时仍可见，并提高浅色、深色桌面内容上的对比度。
- 保留原生自由拖动和位置记忆，不增加展开或收缩控件。
- 缩短浏览器菜单名称，便于快速查找。
