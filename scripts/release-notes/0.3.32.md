## Changes

- Restore the compact download status beside the browser’s More Actions menu.
- View filenames, live progress, transferred sizes and completion or failure in a small download list.
- Reveal individual files in Finder and clear finished records without removing files or hiding active transfers.

## 更新内容

- 恢复浏览器右上角更多菜单旁的紧凑下载状态。
- 通过小型下载列表查看文件名、实时进度、已下载大小及完成或失败状态。
- 可在访达中定位单个文件，并清除已结束的记录；不会删除文件，也不会隐藏正在下载的任务。
