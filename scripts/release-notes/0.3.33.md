## English

- Return to your most recently used web app with Command-Tab or the system Dock, including windows collapsed into the activity Dock.
- Running web apps share one NeatWebApp entry in the app switcher and system Dock. Warm standby helpers stay hidden, and the entry disappears when no web apps are running.
- Switching back restores the existing page and session instead of opening settings. The notch launcher, activity Dock and automatic window collapse remain available.

## 简体中文

- 支持通过 Command-Tab 或系统程序坞回到最近使用的网页应用，已收进悬浮 Dock 的窗口也能恢复。
- 正在运行的网页应用共用一个 NeatWebApp 切换入口和系统程序坞图标；预热进程不显示，没有网页应用运行时该入口自动隐藏。
- 切回时恢复原有网页和会话，不会弹出设置；顶部刘海、悬浮 Dock 和窗口自动收起保持可用。
