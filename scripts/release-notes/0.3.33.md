## English

- Switch directly to each running web app with Command-Tab or the system Dock, including windows collapsed into the activity Dock.
- Each web app uses its website icon in a consistent Apple-style rounded rectangle. The host and warm standby helpers stay out of the Dock and app switcher.
- Switching back restores the existing page and session without opening settings. The notch launcher, activity Dock and automatic window collapse remain available.
- Keep the notch launcher's Add button visible when website icons scroll, and open the management window directly from that button.

## 简体中文

- 支持通过 Command-Tab 或系统程序坞直接切换到每个正在运行的网页应用，已收进悬浮 Dock 的窗口也能恢复。
- 每个网页应用使用自己网站的图标，统一呈现苹果风格的圆角矩形；主程序和预热进程不占系统 Dock 或应用切换列表。
- 切回时恢复原有网页和会话，不会弹出设置；顶部刘海、悬浮 Dock 和窗口自动收起保持可用。
- 网页图标滚动时，顶部刘海的加号始终可见，并可直接打开管理窗口。
