## English

- Bookmark rows now have a native right-click menu with Open, Rename, Add WebApp and Delete. Rename edits only the title; blank names are rejected.
- Add WebApp creates an isolated web app from the bookmark's title and saved URL without reopening the management window. Source HTTP cookies, including HttpOnly and session cookies, are copied through a one-time Keychain handoff and imported by the destination runtime before its first navigation; the two apps stay isolated afterwards.
- Website icons now recover without restarting the host. Transient load failures retry with capped backoff, and memory pressure only pauses speculative prefetching without blocking requested icons.

## 简体中文

- 收藏夹每行新增原生右键菜单：打开、重命名、添加为网页应用、删除。重命名只改标题，不接受空白名称。
- 从收藏直接添加网页应用时，沿用该收藏的标题与完整链接，无需再打开管理窗口手动填写。来源的 HTTP Cookie（含 HttpOnly 与会话 Cookie）经一次性钥匙串交接，由目标运行时在首次导航前导入；新旧应用之后保持隔离。
- 网站图标加载失败后无需重启即可恢复：短暂失败按上限退避重试，内存压力只暂停推测性预取，不阻塞用户请求的图标。
