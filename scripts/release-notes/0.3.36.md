## English

- Each web app window now shows the app's name centered in the top chrome band, with the same borderless treatment as the surrounding icons. The title hides instead of truncating when the window is too narrow to fit it.

## 简体中文

- 每个网页应用窗口顶部正中间显示该应用的名字，和两侧图标一样不画底板、不加描边；窗口窄到放不下时直接隐藏，不截断。
