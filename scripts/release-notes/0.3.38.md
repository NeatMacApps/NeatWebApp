### English

- Stabilize page element hiding across dynamic sibling updates and CSS Modules hash changes, avoiding accidental hiding of unrelated elements.
- Replace "Dock Starting Position" in General Settings with "Show Web Apps in System Dock" and "Show Floating Dock" toggles. Turning off the floating Dock pauses 80% occlusion auto-collapse while keeping `×` / `⌘W` session preservation.
- Use gentle update reminders instead of silent automatic installation.

### 简体中文

- 加固网页元素隐藏选择器的稳定性，在动态增减节点与 CSS Modules 哈希变化后仍能准确命中目标元素，避免误藏其他内容。
- 移除通用设置中的「Dock 初始位置」，新增「在系统 Dock 显示网页应用」与「显示悬浮 Dock」两个开关；关闭悬浮 Dock 时停止遮挡 80% 自动收起，同时保留 `×` / `⌘W` 隐藏并维持会话。
- 改为温和的更新提醒交互，不再在后台静默自动覆盖安装。
